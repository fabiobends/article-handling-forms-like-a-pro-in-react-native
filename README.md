# Handling Forms Like a Pro in React Native

Companion code for the article **"Handling Forms Like a Pro in React Native"**.

This repo walks through building a production-quality form in React Native / Expo — from a bare-bones starting point to a polished, accessible, user-friendly result.

## Branches

| Branch         | Description                                  |
| -------------- | -------------------------------------------- |
| `main`         | Default Expo scaffold — clean starting point |
| `initial-form` | Basic form with no validation or UX polish   |
| `final-form`   | Finished form with all improvements applied  |

## Running the project

```bash
npm install

npm start
```

To try a specific stage, check out the corresponding branch first:

```bash
git checkout initial-form   # before
git checkout final-form     # after
```
